WingCart -- E-Commerce Platform
================================

WingCart is a full-stack e-commerce platform designed for selling watches, providing a smooth and secure online shopping experience.

The platform allows users to browse products, manage their cart, and complete purchases seamlessly.

Overview
--------

WingCart enables customers to explore a curated collection of watches and complete purchases through a secure checkout system.

The platform focuses on:

- Clean user experience  
- Secure authentication  
- Efficient order management  
- Reliable payment processing  

Key Features
------------

Product Catalog

- Browse a wide range of watches  
- View detailed descriptions, images, and pricing  
- Organized product listing for better usability  

Shopping Cart

- Add products to cart  
- Update quantities  
- Remove items  
- Proceed to checkout  

User Authentication

- Secure sign-up and login system  
- Account management  
- Order history tracking  

Order Management

- Admin panel to manage orders  
- Inventory tracking  
- Order status updates  

Payment Integration

- Secure Razorpay payment gateway  
- Safe and seamless transaction handling  

Product Search & Filtering

- Search products by keywords  
- Filter by price, brand, and category  

Responsive Design

- Optimized for desktop and mobile devices  
- Consistent and user-friendly interface
